# AutoBOX Ungheni - ERP System

> Sistem Management Integrat pentru Autoservice

## 🚀 Quick Start

### Prerequisites
- Node.js 20+
- npm or yarn

### Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Open browser
# http://localhost:5173/1/
```

### Production Build

```bash
# Build for GitHub Pages
npm run build

# Preview production build
npm run preview
```

## 📁 Project Structure

```
.
├── src/

```

## 🌐 Deployment

The project is configured to deploy to GitHub Pages at:
- **URL**: https://autoboxun.github.io/1/
- **Source**: `/docs` folder from `main` branch
- **Auto-deploy**: On every `git push` via GitHub Actions

## 🛠️ Available Scripts

- `npm run dev` - Start development server with HMR

- `npm run preview` - Preview production build locally
